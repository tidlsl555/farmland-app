# 현장 운영 방법

## 작업 체크

1. 하단에서 작업을 선택합니다.
2. `빠른 작업`을 켭니다.
3. 지도에서 농지 필지 경계를 누릅니다.
4. 상단 카운터는 선택한 작업의 완료 수만 표시합니다.

완료 기록은 삭제하지 않습니다. 취소하면 별도의 취소 이벤트가 생성됩니다.

## 작업 취소

- 하단 `최근 작업 취소` 버튼은 시간 제한 없이 마지막 활성 완료 기록을 취소합니다.
- `작업 기록`에서는 더 이전의 완료 기록도 취소할 수 있습니다.
- 취소된 기록은 `복원`으로 새 완료 이벤트를 만들 수 있습니다.

## 물관리

작업을 `물관리`로 선택했을 때만 물관리 상자가 나타납니다.

1. 지도에서 농지 선택
2. 물관리 시작
3. 경과시간과 48/72시간 진행 확인
4. 물관리 종료

잘못 시작한 기록은 취소 상태로 남길 수 있습니다.

## 위치 관리

### 자동 필지경계

관리자만 브이월드 일괄조회를 실행할 수 있습니다.
주소 좌표 주변 WFS 결과에서 리명과 지번이 모두 일치한 필지만 저장됩니다.

### 현장 GPS

자동조회 실패 농지에서 `현장 GPS`를 누릅니다.

- 경계가 있고 GPS 정확도가 30m 이하이며 점이 경계 안이면 `경계+GPS 확인`
- 경계가 없으면 `GPS 점만 등록`
- 경계 밖이거나 오차가 크면 `검증 필요`

GPS 점만 등록된 농지는 정확한 필지 경계로 계산하지 않습니다.

### 경계 직접 그리기

관리자가 필지 외곽을 지도에서 순서대로 누르고 시작점을 다시 누르면 폴리곤이 완성됩니다.
확인 후 저장하면 `직접 그린 경계` 상태가 됩니다.

## 데이터 보호

- 모든 사용자는 로그인해야 합니다.
- 브라우저에는 publishable/anon key만 둡니다.
- service role과 브이월드 서버 키는 Edge Function secret에만 둡니다.
- 공개 저장소에 농지 seed 파일을 올리지 않습니다.
- 정기적으로 데이터 관리에서 JSON 백업을 내보냅니다.

## 정확도 해석

브이월드 연속지적도는 현장관리용 참조 도면입니다.
토지 분쟁, 경계 확정, 측량 업무에는 지적측량 결과를 사용해야 합니다.
